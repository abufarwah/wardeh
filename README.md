# 🌸 Wardeh Store

A fully responsive, dynamic E-Commerce Front-End Web Application for a flower and gift shop.

## 🌟 Overview
Wardeh Shop started as a static website and has been upgraded into a fully functional Front-End application. It features a modern design, dynamic data rendering, and a working shopping cart built entirely with Vanilla JavaScript, HTML5, CSS3, and Bootstrap 5.

This project is a perfect demonstration of translating static UI into interactive, component-like dynamic architecture.

## 🚀 Key Features

* **Dynamic Rendering:** Products are loaded and generated via JavaScript data structures rather than hardcoded HTML, mimicking how APIs operate in real-world applications.
* **Fully Functional Shopping Cart:** 
  * Add, remove, and update quantities of items.
  * Instant calculation of total prices and item counts.
  * Beautiful offcanvas drawer UI for the cart.
* **Persistent Local Storage:** Cart data is saved in the browser's `localStorage`, meaning users won't lose their selected items if they refresh or close the tab.
* **Product Filtering:** Instant, client-side category filtering (Flowers, Chocolates, Gifts) without page reloads.
* **Interactive UI/UX:** 
  * Bootstrap Toast notifications alert the user whenever an item is added to the cart.
  * Form validation on the newsletter subscription to ensure a smooth user experience.
* **Fully Responsive:** Adapts beautifully across mobile, tablet, and desktop screens.

## 🛠️ Technologies Used
* **HTML5** & **CSS3** (with custom styling and animations)
* **Vanilla JavaScript** (ES6+ for DOM manipulation, Event Delegation, and Local Storage logic)
* **Bootstrap 5.3** (Grid system, Modals, Offcanvas, Toasts)
* **Font Awesome 6** (Icons)
